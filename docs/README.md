# OctoAcme Project Management Docs

This repository contains the OctoAcme project management process documentation used to guide project work from initiation through delivery and continuous improvement.

## Project management process summary
OctoAcme uses a lightweight, cross-functional project lifecycle that starts with project initiation, moves into planning and backlog definition, manages execution and tracking through daily work and milestones, and closes with release, retrospective, and improvement actions. The process emphasizes customer value, clear ownership, deliberate communication, risk management, and measurable outcomes.

## How to use this set of docs
Use these documents to align the team on roles, plan work, track execution, handle risks and communication, and improve process quality over time.

## Process lifecycle at a glance
1. Initiation: validate the problem, align stakeholders, and define success criteria.
2. Planning: create the backlog, estimate work, and set milestones and dependencies.
3. Execution: build and track progress while managing blockers and quality gates.
4. Release: confirm readiness, deploy safely, and communicate outcomes.
5. Close & improve: capture lessons learned and turn them into action items.
